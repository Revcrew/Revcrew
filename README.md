## How I work: test, don't trust

1. **Rules first.** Acceptance criteria, thresholds and PASS bars are
   written down before the results exist — never adjusted to fit them.
2. **Verify on real data.** Tests are re-run, numbers are recalculated,
   and claims are traced to primary sources, not to an agent's summary.
3. **Publish the verdict.** A negative result is a result. If a strategy
   has no edge, or a tool fails its own bar, that goes in the README too.
